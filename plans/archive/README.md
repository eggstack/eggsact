# Archive

Completed, superseded, or abandoned interim planning retained for
traceability.

- Archive moves MUST preserve traceability and SHOULD retain original
  filenames and subsystem grouping.
- Canonical long-term documents and accepted ADRs MUST NOT be archived
  merely because their initial implementation completed.
- The legacy single-doc era (`roadmap.md` plus flat `*.md` files with
  closure records appended to the same file) is retained here. Do not
  edit archived files except for factual corrections; new work uses
  `plans/subsystems/`, `plans/implementation/`, and `plans/closure/`.

  `plans/000-003` + `plans/registry.md` + subsystem roadmaps).
