# Workstream 6 — Verify the crates.io release

## 6.1 Version API verification

Query the exact version until available, using a bounded retry window appropriate for index/API propagation:

```bash

import time
import urllib.error
import urllib.request

url = "https://crates.io/api/v1/crates/eggsact/1.2.0"
headers = {"User-Agent": "eggsact-release-verification"}
last_error = None
for attempt in range(12):
    try:
        req = urllib.request.Request(url, headers=headers)
        with urllib.request.urlopen(req, timeout=30) as response:
            payload = json.load(response)
        version = payload.get("version", payload)
        print(json.dumps(version, indent=2, sort_keys=True))

else:

PY
```

- version number;

Before crates.io accepts `1.2.0`, any failed preflight may be corrected only by stopping and creating a new corrective plan. Do not modify `75ea503` in place.

- do not yank solely because tagging is incomplete;

- fix on `main`;
- increment the version;
